# 나만의 방 서버판

로그인 없이 링크만으로 들어온 사람들이 서로를 볼 수 있는 버전이에요.
한 서버에서 방 주인을 포함해 **먼저 들어온 10명**이 방 안에서 마주치고, 그다음 사람부터는 자리가 날 때까지 구경하며 기다려요.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `server.js` | 페이지를 보여주고, 방문자 위치·이름·캐릭터를 실시간으로 주고받는 서버 |
| `room.html` | 방 화면. 상위 폴더의 `my-room.html`을 복사한 파일이에요 |
| `package.json` | 서버 실행에 필요한 설정 (`ws` 라이브러리 하나만 써요) |

방 화면을 고친 뒤에는 `my-room.html`을 이 폴더에 `room.html`로 다시 복사하세요.

## 내 컴퓨터에서 먼저 켜 보기

[Node.js](https://nodejs.org) 18 이상을 설치한 뒤 이 폴더에서 아래 명령을 차례로 실행해요.

```bash
npm install
```

```powershell
$env:OWNER_KEY="원하는-주인-키"; npm start
```

브라우저에서 `http://localhost:3000` 을 열면 방문자 화면이에요.
방 주인 화면은 `http://localhost:3000/#owner` 로 열고 위에서 정한 주인 키를 입력하면 돼요. 한 번 입력하면 그 기기에서는 기억해요.

## 인터넷에 올리기 (Render 무료 플랜 예시)

1. 이 `server` 폴더를 GitHub 저장소에 올려요.
2. [render.com](https://render.com)에 가입하고 **New → Web Service**에서 그 저장소를 골라요.
3. 설정을 이렇게 넣어요.
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Environment Variables: `OWNER_KEY` = 나만 아는 긴 문자열
4. 배포가 끝나면 `https://○○○.onrender.com` 주소가 생겨요. 이 주소를 지인들에게 보내면 돼요.
5. 내 상태를 바꿀 때는 `https://○○○.onrender.com/#owner` 로 들어가 주인 키를 입력해요.

웹소켓을 지원하는 다른 Node 호스팅(Railway, Fly.io 등)도 같은 방식으로 쓸 수 있어요.

## 알아둘 점

- **주인 키는 비밀번호예요.** 링크에 붙여서 보내지 말고, 나만 아는 긴 문자열로 정하세요.
- Render 무료 플랜은 15분 동안 아무도 없으면 서버가 잠들어요. 다음 사람이 들어올 때 깨어나느라 30초쯤 걸릴 수 있어요.
- 무료 플랜은 서버가 다시 시작되면 저장된 내 상태가 처음 값으로 돌아갈 수 있어요. 오래 유지하려면 디스크가 붙는 유료 플랜을 쓰거나 `DATA_DIR` 환경변수로 영구 저장 경로를 지정하세요.
- 방문자 위치와 이름은 서버에 저장하지 않아요. 접속해 있는 동안에만 주고받아요.
- 동시에 연결할 수 있는 사람은 60명까지예요. 그중 방 안에 들어가는 건 먼저 온 10명이에요.
